\section*{Hypothesis}

If we say that \textsc{SimpleTotal} increments the total exactly
$1 + \sum_{k=5n}^{7n} k$ times for some input of $n$, we can conclude the
Big-O time complexity is $O(n^2)$ if, for a given input $n$ and a positive
constant $c$,
\[
  1 + \sum_{k=5n}^{7n} k \;\le\; c \cdot n^2.
\]

The summation can be written as
\[
  1 + \sum_{k=5n}^{7n} k
  = 1 + \sum_{k=1}^{7n} k - \sum_{k=1}^{5n} k
  = 1 + \frac{7n(7n+1)}{2} - \frac{5n(5n-1)}{2}
  \;\Rightarrow\; 12n^2 + 6n + 1.
\]

Similarly, we can write the following inequality substituting the summation
with our polynomial:
\[
  12n^2 + 6n + 1 \;\le\; c \cdot n^2.
\]

\subsection*{Base case}

In order to prove this for a growing input $n$, we first need a base case.
We choose $n_0 = 1$ as a positive non-zero input.
\[
  12(1) + 6(1) + 1 \le c \cdot (1)^2
  \quad\Longrightarrow\quad
  19 \le c.
\]

The inequality is true where $c \ge 19$. Now we show that this relation
holds for a growing input, say $n = x + 1$.

\subsection*{Inductive step}

\begin{align*}
  12(x+1)^2 + 6(x+1) + 1 &\le c \cdot (x+1)^2 \\
  12(x^2 + 2x + 1) + 6x + 7 &\le c\,(x^2 + 2x + 1) \\
  12x^2 + 24x + 12 + 6x + 7 &\le c\,(x^2 + 2x + 1) \\
  12x^2 + 30x + 19 &\le c\,(x^2 + 2x + 1)
\end{align*}

Where $c = 19$, we prove that \textsc{SimpleTotal} is bound by $O(n^2)$:
\[
  12x^2 \le 19x^2.
\]
